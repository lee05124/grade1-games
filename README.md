# 橡果森林

國小一年級益智遊戲，打開網頁就能玩，不需要登入。小朋友幫小松鼠收集橡果，每個遊戲都有語音唸題目。

- 加減小松鼠：50 以內的加減應用題，卡住可以看十格框提示
- 注音找朋友：看圖選開頭的注音、看注音選圖
- 國字配注音：80 個一年級常見國字，練習分辨四聲
- 水果排排站：找出 AB、AAB、ABB、ABC 規律
- 數數小動物：20 以內點數
- 拼圖小森林：8 張圖，4、9、16、25、36 片五種難度
- 對還是錯：是非題，動物、生活安全、數學、國字注音

整個遊戲只有 `index.html` 一個檔案，用瀏覽器直接打開就能玩。要修改題庫，編輯檔案裡的 `HANZI`（國字注音）、`WORDS`（注音詞語）和 `TF_BANK`（是非題）三個清單即可。

# 小松鼠學習園

另一個一年級練習遊戲，檔案是 `xiaosongshu.html`。分成數學、國語、生活三科，共 13 關，每關 10 題。答錯會給提示，錯兩次會顯示答案；只有第一次就答對的題數會算進星星。

- 數學：數一數（20 以內）、加法、減法（用十格框看湊十）、比大小
- 國語：注音拼讀、認國字、量詞、筆順、相反詞
- 生活（自然）：動物、植物部位、天氣季節、垃圾分類

一、二年級沒有獨立的自然科，自然內容在「生活課程」裡，所以這一科標成「生活」。垃圾分類只放各縣市分法一致的物品，實際仍以居住地環保局公告為準。

要修改題庫，編輯檔案裡的清單：`ZY1`（注音）、`ZI1`（國字）、`LC1`（量詞）、`BHQ`、`BHN`（筆順與筆畫數）、`FX`（相反詞）、`AN1`（動物）、`PL1`（植物）、`WX1`（天氣）、`TR1`（垃圾分類）。

# 小一闖關本

第三個一年級練習遊戲，檔案是 `xiaoyi.html`。四科做成作業簿封面，共 11 關，每關 10 題，答對 9 題以上得 3 顆星。

- 數學：加法、減法、加減混合，50 以內隨機出題，含進位、退位；用數字鍵盤作答，可看十位條、個位方塊提示
- 國語：筆順描寫（看示範後用手指或滑鼠照順序寫）、筆順小考（第幾筆、共幾畫）、部首找一找
- 自然生活：植物、動物、生活安全
- 英文字母：大小寫配對、聽聲音選字母、看圖找開頭字母

筆順資料來自開源的 Make Me a Hanzi（依大陸標準），所以只收台灣與大陸筆順一致的 27 個基本字，建議對照[教育部筆順學習網](https://stroke-order.learningweb.moe.edu.tw/)。筆順描寫需要連網載入 hanzi-writer。

要修改題庫，編輯檔案裡的清單：`STROKE_CHARS`（筆順字）、`RADICALS`（部首）、`NATURE`（自然生活）、`WORDS`（英文單字）。新增筆順字時，`STROKES` 也要放入該字的筆畫資料。
